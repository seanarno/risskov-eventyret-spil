# Risskov-eventyret (spillet)

Her ligger den færdige, spilbare udgave af Risskov-eventyret: et 3D-platformspil i browseren om en gåtur med hunden Liva fra Egå Marina langs stranden til toppen af Djævlebakken i Riis Skov.

Spil det på GitHub Pages-adressen for dette repo. Det virker på computer, iPad og iPhone.

Repoet indeholder kun den byggede fil (`index.html`). Kildekoden bliver udviklet et andet sted.
